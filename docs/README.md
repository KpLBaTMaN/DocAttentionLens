# Documentation

Start with the [application overview and quick start](../README.md). These guides
keep detailed instructions separate from the application showcase:

- [getting-started.md](getting-started.md): running locally, the GPU profile,
  configuration, persistence and backups.
- [methods.md](methods.md): region ownership, measurement definitions, linked
  inspection and interpretation limits.
- [development.md](development.md): native development, repository structure,
  tests and verification.
- [examples.md](examples.md): the committed example datasets, how the tables were
  annotated and how to rebuild them.

## Reference material

The following documents are kept outside the application source. Nothing here is
read by a build, a test or the running application.

- [frontend-behaviour.md](frontend-behaviour.md): detailed behaviour and design notes
  for frontend components, by file. The source keeps a one-line summary of each.
- [python-notes.md](python-notes.md): measurements and history behind backend and
  library rules, such as retriever kernel calibration and GPU memory admission.
